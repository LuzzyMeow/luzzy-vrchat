工具链/素材/上传见 `01-05-babystep-toolchain-and-upload.md`；MA 菜单与开关配方见 `03-04-ma-menu-and-switch-cookbook.md`。

## §1 开工前的模型精简

作者口径：**先精简再绑东西**（删网格 / 删骨骼 / 删参数 / 删菜单 / 整理层级）。精简省下的槽位与节点，直接决定后面还能加多少功能。

### §1.1 删骨骼（先确认是否有人用）

- 判定方法：**移动骨骼看有没有东西跟着动**；跟着动 = 还在用，别删。
- ⚠️ **隐藏的呆毛骨骼可能被缩成一个点**：误删后会出现**「从世界出生点一直连着你的一根长线」**（骨骼消失导致蒙皮拉伸）。
- **脸部骨骼可把 Pose 设为 false**（不允许别人摆 pose），不必删。
- **绿色 = 碰撞体（Collider）、蓝色 = VRC 接收器（拍头）**，别乱动。物理与碰撞体语义见 `07-01-bake-and-validation.md` §7 与基底 `../00-基底/00-03-physbone-dynamics.md`。

### §1.2 删参数（先看占用）

1. **先运行 Avatars 3.0 Manager** 看菜单/参数的实际占用（否则不知道哪个参数还在被控件调用）；
2. **子菜单里的控件参数要一并删**（只删桌面上的会留下孤儿参数）；
3. 作者示例：**只保留 4 个参数 = float 8 槽 + 3 个 bool = 11 槽**；
4. 参数面板字段语义：`default`（默认值，如 float 0.5 / 1 = 最大）、`saved`（进新地图是否保留）、`synced`（作者说几乎都开着）。

> 完整的成本公式、每页控件上限与「四表面同步」见 `03-01-parameter-and-menu-audit.md`；**不要凭这里的 11 槽去做预算**，示例只是当时的取舍。

### §1.3 整理层级（注意插件的路径依赖）

- 新建**空对象当分类文件夹**，命名如 `0` / `hair`，把头发 / 衣服 / 配饰分门别类拖进去。
- ⚠️ **很多功能插件要求对象放在人物的「直接子级」**：有的插件**靠路径定位**，乱加层级会导致功能失效。→ 整理时先确认每个功能插件的路径要求（参考 `07-03-provider-playbooks.md` 的 provider 链）。
- 空对象与分类对象的所有权/消费者关系见 `07-02-evidence-and-ownership.md` §4。

### §1.4 衣服怎么组织

- **按「一套一套」组合**（不喜欢逐件开关：一套 = 若干件一起切换）。
- **一个 int / float 换装参数比一堆 bool 省槽**（1 个 int = 8 槽换 256 档；若用 bool 每件 1 槽但会重叠，见 §3.7）。

## §2 如梦工具箱（VRC工具箱）衣柜：生成、转移与参数占用

> 插件身份与安装见 `01-05` §1.4（**`VRCAvatarToolkit`**，Unity 顶部「VRC工具箱」，FX 层只占 1 个参数槽）。

### §2.1 生成流程

1. 把衣服搭配好 → 打开工具箱的「**我的衣柜**」；
2. **把人物拖入** → 「**创建衣柜**」；
3. 每一套衣柜**加两个元素**（示例：外套 + 鞋）；
4. 可以对单件做「**换色 / 透明切换**」；
5. 「**一键应用到模型**」。

### §2.2 它生成的到底是什么（原理）

- **一个 int 参数**（占 **8 槽**）；
- **FX 里的新层**：任意状态 → 默认 / 各套动画，**只能同时出现一套**（互斥由 int 天然保证）；
- 菜单里出现「**换装**」子菜单；
- 容量：**可加 256 套 / 换色**；**适用于衣服与头发**；**配饰想同时出现要用「配饰」功能（bool）**（不要塞进衣柜）。
- 生成物属于 **provider 生成输出**：**不要手改**，要改就改源配置或复制出来改（见 `07-02-evidence-and-ownership.md` §6）。

### §2.3 转移并保存如梦生成的换衣系统（6 步，教程强调必做）

| 步 | 动作 | 不做会怎样 |
|---|---|---|
| ① | **文件夹重命名换地方**：`Assets\AvatarData\` 里如梦建的第一个文件夹 → 重命名（如「如梦衣服」）并移到自己建的文件夹 | **下次再用衣柜会被覆盖，动画全乱套** |
| ② | **参数重命名**：人物参数里把如梦用的 `int0` 改名 | 每次刷新又新建一个同名 `int0`（参数越滚越多） |
| ③ | **菜单重命名**：「换装」改成「衣服」，并进去改子菜单名 | **「换装」两字被如梦锁定**，不改会被新生成的覆盖 |
| ④ | **重选参数**：菜单里每个控件手动改到重命名后的参数 | 控件指向旧参数 → 点了没反应 |
| ⑤ | **FX 参数重命名**：FX 层参数名必须与参数槽一致（改完菜单调用会自动跟随） | 层里参数与槽对不上 → 换装不生效 |
| ⑥ | **改动画**（按新的参数/对象命名整理动画引用） | 动画引用旧路径 → 播不出正确外观 |

> 不需要再生成第二套时，可跳过整段；但**只要以后还会用衣柜，就必须按 6 步做**。这与 `02-01-workspace-and-work-assets.md` §3.1「可选 prefab 只被 FX clip 相对路径引用时的处理」是同一类问题（**动画靠路径引用，移动/改名必须同步**）。

### §2.4 菜单精简与控件语义

- 把两套衣服塞进**子菜单**（一级菜单只留入口）；
- 控件类型区别：**「按一下变一次、不保存」= 普通按钮**；**「切换并永久保存」= Toggle**；
- 作者示例的参数值：护士 = 3、护士白 = 8（原「下一页」只有一个 `SM=7` 的控件，**可删掉「下一页」改建为子菜单**）。
- 菜单上限、`More` 分页与 MA 菜单路由见 `03-01-parameter-and-menu-audit.md` §2。

## §3 录动画、换色、形态键与配饰

### §3.1 录动画前把 Animator 的 Controller 设为 None

- **录动画前：Animator 组件的 Controller 选 `None`**，避免录制过程中人物乱跑 / 乱切动作（录进去多余关键帧）；
- **上传前或用 Gesture Manager 测试前必须选回原 Controller**（忘了选回 = 模型在游戏里没有动画）。
- 录制/改动画的幂等与验收纪律见 `07-04-verification-discipline.md`、`07-01-bake-and-validation.md` §5。

### §3.2 浏览人物所有动画的窍门

- 新建一个动画控制器 → **把人物控制器拖进 Animator 窗口的层级** → **双击人物**即可浏览/切换；
- 也可以用「衣服」控制器统一改动画（把改动集中在自己的控制器里，不改别人的层）。

### §3.3 穿模与运行时优化

- **鞋子穿模**：从 Blendshape 里找**高跟鞋形态键拉到最高**（鞋子形变配合脚型）；
- **运行时优化**：把**被鞋子/身体覆盖的部分缩小**以减少网格计算（不可见区域的顶点/面尽量小）。
- 完整的穿模风险顺序（先隐藏互斥几何 → 形变/蒙皮 → 局部顶点修改，**不做补片加面**）见 `05-01-outfit-fit-and-clipping.md` §E1；几何验收见其 §E2。

### §3.4 换色：必须用「材质引用」录进动画

- 做法：**把材质直接拖进动画**（产生「材质引用/材质替换」曲线）→ 该动画切到已换色状态；
- **一共 8 个材质槽**（作者示例口径），注意别超；
- ⚠️ **单独改材质资产不会录进动画**：必须在裙子（Skirt/材质）界面里调颜色，才会被记录。→ 材质实例 vs 共享资产的判定见 `04-01-appearance-and-liltoon.md`；颜色来源分层见 `04-03-color-and-puppet.md`。

### §3.5 形态键联动

- 例：把「**舌嘴**」形态键**绑定到人物嘴型 A**（人张嘴时舌头跟着动）。
- 形态键/驱动链改动的只读排查与曲线写回纪律见 `04-02-expressions-and-icons.md`（**先排驱动链，再动曲线**）。

### §3.6 绑头发：先重命名根骨骼，再用 Bone Proxy

- **头发 prefab 直接「set out」不行**：因为**它的骨骼根就是头发根**（不是挂在头上的）；
- 正确流程：
  1. **先重命名头发根骨骼**（防与人物骨骼重名，重名会导致 Bone Proxy 选错目标）；
  2. 用 **`ModularAvatarBoneProxy`（附加骨骼）** 把头发根骨骼**附加到头骨骼**上，使其成为头的子级；
  3. **没有 `hips` 的头发同理**（按需要挂到的最近骨骼处理）。
- Bone Proxy 与 Merge Armature 的选择铁律见 `03-03` §（MA Merge Armature vs MA Bone Proxy）与 `07-03-provider-playbooks.md` §1。

### §3.7 头发开关：bool 重叠的两个解法 + 极限优化

- 3 个布尔配饰（原发默认显示，白发 / 狼发默认隐藏）；
- ⚠️ **布尔开关会重叠**（两个同时开就穿模/叠在一起），两种解决：
  1. **换成一个 int / float**（同一图层里互斥，见 `03-04` §3）；
  2. **逐个改动画**，让某款显示时关掉其它头发；
- **极限优化**：把**头发动画并进衣服动画**（某套衣服只配某一款头发 → 删掉头发参数、FX 层、菜单，直接省槽）。

### §3.8 默认值修改与「缺形态键」的情况

- 参数面板 `default` 改成对应值（例：运动装 = 4 → 默认就是运动装；`set` 改成 1 → 默认最大）；
- **有的衣服没有最大形态键** ⇒ 需要**给那套衣服单独录大小动画**（不要假设所有衣服都有同一套形态键）。

### §3.9 配饰骨骼与动骨参数收尾

- **长在头发上的物件**：直接用 **一个 MA Bone Proxy** 绑到头；
- **挂在衣服上的**：同样方式拖到对应骨骼（示例 `spin chest`）下；
- **翘边 / 半径过大是动骨（PhysBone）问题** → **半径设为 0 + 用角度限制**（详细参数语义见 §5）。

### §3.10 教程最终的参数占用

- **18 槽** = 换衣换色 int（8 槽）+ 3 个配饰 bool（3 槽）+ 其余并入衣服动画或固定物品（不再单独占参数）。

## §4 Blender 侧：从 0 建骨骼与刷权重

> 目标示例：给「**什么骨骼都没有的帽子**」加两根会晃、可被抓起的耳朵骨骼。

### §4.1 建骨骼

1. 在 Unity 里点网格定位 → 资源管理器里找到它的 `.fbx`、**复制路径** → 导入 Blender；先把键位映射调好（`Tab` 调出菜单）；
2. 选中骨骼进**编辑模式**；打开**名称显示**（可见 `Head`、`head_end`）；
   - **`_end` 一般是叶骨**（保护骨骼、通常零权重）；
3. **先确认原有权重**：选中骨骼 + Shift 加选帽子 → `Tab` 进**权重模式** → **红 = 权重最高、紫 = 不被该骨骼控制**（示例整个帽子原本由 `head` 控制）；
4. 建新骨骼：编辑模式从目标位置按 `E` **挤出**一根（示例沿 Z 向上）→ 命名如 `ear2.root`；`Alt+Z` 开**透视模式**对准；
5. 骨骼属性里**取消「相连项 / Connected」**才能自由拖动（示例把耳朵往下、趋于中间）；
6. 左右命名注意镜像方向（面朝前时左在一侧；全部骨骼同一套命名：`ear2.L` / `ear2.R`）；
7. 做好左侧后 **点根骨骼按 `L` 选中整链** → 右键 **对称（Symmetrize）**；
8. **实时 Ctrl+S**；**检查父子级**（有线连着说明父级对）；
9. **把原 `head_end` 这类叶骨删掉并把骨骼设为相连**——**叶骨加不加对 VRChat 影响不大，因为动骨自带骨骼保护；做 VRChat 模型不需要手动加叶骨**。

### §4.2 刷权重（自动权重实测不可用）

- 快捷法：**选中帽子 → 再选骨骼（顺序不能反）→ `Ctrl+P` → 附带自动权重**；
  **实测很差**：`root` 本该是空的却控制了下面一大片、耳朵根控制帽子太多、上面骨骼控到下面 → **不能接受**；
- 推倒重来：骨骼属性 → 顶点组 → **删除全部组**
  ⚠️ 作者提醒：**人物 / 衣服绝不能这么干**（这个帽子原本只有 `head` 一根、全红好复刻，属特例）；
- 正确路径：仍按「**先帽子后骨骼**」`Ctrl+P` → **附带空顶点组** → 选中帽子 → **权重绘制**：
  - `head` 用**梯度线（线性权重）**从远到近过渡；整片要红就刷满；
  - 每根耳朵骨骼先限范围：编辑模式选最高顶点 → **扩展选区** → 回物体模式进权重 → 按 `M` **遮罩** → 先全给红（遮罩外自动过渡）→ 再换权重 0 刷小过渡；
    ⚠️ **遮罩刷子是完全透视的，刷前面后面也会变**；
  - 帽子有倾斜导致前后权重不对 → **从另一侧重刷** + **模糊工具**（`Shift` 力度、`F` 笔刷大小）前后左右模糊；
- **对称传递两种**：
  1. **镜像顶点组**（权重组名去掉 `L` 后点镜像；网格不对称时用**镜像拓扑**）；
  2. **镜像刷**（选右边顶点组点镜像，刷左侧同步；权重 0 不控制网格）；
- **网格片太大时小笔刷刷不动**（要放大笔刷）；每步进**姿态模式**验证控制范围。

### §4.3 导出 FBX → 在 Unity 里做新网格并复制组件

- Blender 导出 FBX：勾 **`FBX（全部）` + 添加叶骨 + 取消「烘焙动画」**；
- Unity `Ctrl+R` 刷新 → 出现新网格；
- **为什么不直接替换**：这个物品**原本没有这些骨骼**，直接替换会乱 → **先做新的再替换**；
- 在**锁定的 Inspector** 里把**形态键逐个复制**过去（帽子特例；正常模型没这么多形变要改）+ **材质球拖过去**；
- **位置对齐**：原帽子有 `0.221` 偏移 → 新帽子也加 `0.21` 即重合（**位置对不上先查变换，不要动网格**）；
- **组件迁移**：在原对象上组件右键「**复制组件**」→ 新对象「**粘贴为新组件**」；旧的那套基本可丢。

## §5 `VRCPhysBone` 参数详解与调试循环

**先点组件旁的小问号**：内置提示会列出所有参数含义，**对照看比听口播准**。
**版本：用 1.1**（`PhysBone 1.0` 少了拉伸、阶段性控制等）。

| 参数 | 作者口径 |
|---|---|
| Root Transform | 把组件挂到新建空对象、把 Transform 拖进去，**动骨效果完全一致**——便于精细修改与快速定位 |
| 忽略（槽位） | 填几根骨骼 = 这些骨骼从该动骨根部起不受控制（放 2 根少一块；只放 `R` 整条右边没了）。用途：① 让某段尾部不受影响 ② **在被忽略的骨骼上另设一个更夸张的动骨** |
| 末端骨骼 / 叶骨 | 长度变 0 会少一段骨骼（等于手动增删一段）；**加很长一段 → 那一段变成可抓的位置**（抓取手柄出现在那里）；不想进 Blender 只想精细控制骨骼时可活用 |
| 忽略方式（平均 / first） | 平均 = 所控物件中心权重平均；`first` = 先被拉的那根；**与「忽略」属同一套极致控制**。作者踩坑：某裙子骨骼**横着长** → 角度限制全斜、一运行就斜飘 |
| 拉力 Pull | 越小 → **慢悠悠回归**；越大 → 爆冲后「邦」地弹回（人往前暴冲时最明显） |
| 弹簧 Spring | 越低越没弹性（爆冲完回来就不动）；越高 → 一直「邦邦邦邦」弹 |
| 重力 / 重力补偿 | 重力向下；**重力补偿像给气球充氦气让人飘起来**；两者对抗平衡 |
| 运动 Motion | **1 = 完全动不了；0 = 可动**；基本保持默认 |
| 高级：硬度 Stiffness | 越高越像**筷子**直挺挺冲过去，而不是有弹性的东西 |
| 限制：角度 | 用**蓝色扇形 / 锥形**标出可动范围 |
| 限制：曲线 | 那些 `C` 是曲线：前面低 = 前面小、后面低 = 后面小 |
| 旋转 Rotate XYZ | 让限制范围整体旋转（如某绺头发不能往后转，作者比作「前面有堵墙」） |
| 限制：H 形（线 / 面） | 只能在一个面 / 一条线上动 → 适用于扇子这种只能前后不能左右的 |
| 限制：极坐标 Polar | 前后左右都能限制：前后给小半径、左右给大半径 |
| 半径 Radius | 手动调；**与碰撞器（Collider）结合**：设了 3 个 Collider，外面那圈与**绿色碰撞体**对齐 |
| 碰撞器 Collider | 形状 **球 / 胶囊 / 平面**；平面画出一个**面 + 一根棍**，**棍指向的一侧「空间存在」、另一侧不存在**（白色为可进入范围）；放在某骨骼下就跟着那根骨骼走；白色范围弯过去会**一节一节贴在球面**上被挡住；用例：**防头发穿胸膛**（面放胸口并转方向）、**防蹲下穿地**（面放脚底、挂 `hips`）；⚠️ **这个面不是小片而是无限大的平面**，极限角度仍可能穿过去 |
| 抓取：抓取长度 | 最常用（示例抓成 5 倍） |
| 抓取：不同骨骼拉伸量 | **前面骨骼被抓时拉伸多、后面少** |
| 抓取：捏 / 压 Press | 抓着往下压：0.7 → 整个压成一片（剩 0.3） |
| 抓取：允许抓取 / 允许摆 Pose | 摆 Pose = VR 里抓起后**按扳机固定**（配合 `_IsGrabbed` / `_IsPosed` 做动画，见 `03-04` §6） |
| 动画控制勾选 | 「这个动骨会被动画控制就勾上」，不涉及别动 |

### §5.1 调试循环（教程原话：动骨是一遍遍试出来的）

- 试运行后**耳朵形态奇怪 / 晃的位置不对** → 判为**弹簧过高** → 调低；
- **抓不住 / 抓不回去** → **半径调大**（示例 `0.0103`）基本包围住 + 调三根骨骼的拉伸量（**后少前高**）；
- 仍有一小部分不对 → 回 Blender **调权重**（对称后力度调低、往下拉一点、再平均）→ 保存 → 导出 → Unity 刷新**自动替换**；
- ⚠️ **只能在非运行状态修改**（以前运行中改也生效，某次更新后不行）；
- 想动得不剧烈 → **弹簧拉低**（示例 0.7）；**太晃 → 拉力高、弹力小**；
- 满意后**保存成预制件**（示例 `rabbit` → 拖成 prefab），即可作为预制件分享 / 导出 unitypackage。

**作者总结：动骨最常用三块 = 形态、防穿模、抓取。**

## §6 fbx 直接替换网格：什么时候能换、什么时候必须重导

### §6.1 前提（教程强调三遍）

**只适用于「没有增减骨骼、也没有改顶点组，只改网格（含形态键）」的情况。**

### §6.2 原理

**Unity 只把「拥有相同顶点组」的网格视为同一网格。**
改过顶点组，或网格初始朝向不同（**Blender 与 Unity 默认朝向轴不同**）→ 就不匹配：
→ 直接替换后**网格消失或扭曲**（作者形容「变成富江」）。

### §6.3 正确流程

| 环节 | 设置 |
|---|---|
| Blender **导入** | 选 **`FBX` 实验性（Experimental，4.5+）** |
| 叶骨 | 按需勾 **「忽略叶骨」**；判定：往下找小三角有无 `END`，**拖 END 不影响骨骼、拖上一级会动** ⇒ 有叶骨需勾忽略 |
| 动画 | **取消** |
| Blender **导出** | 选「可见物体」或 Shift 加选骨架与网格；勾 **`FBX（全部）`**；**叶骨设置与导入相反**（导入取消了叶骨 ⇒ 导出要勾添加叶骨） |
| Unity | `Ctrl+R` 刷新 → 出现新网格 |

### §6.4 检查清单

- 比对**网格九宫格中心 / 尺寸**（示例 `171` 位置对上即对准）；
- 若 size 多出 `0.00` 变小（看起来像消失）⇒ **换缩放规则重试**；
- `Ctrl+R` 后新网格的 **BlendShape 会多出新捏的那一个**；
- **骨骼要与原 FBX（不是 prefab）对比**数量与命名（应有 `Armature` / `ARMRE`），叶骨要与原 FBX 一样。

### §6.5 两个边缘情况

1. **某网格只识别到部分骨骼** → Blender 里**全选网格 + Shift 加选骨架 → `Ctrl+P` → 附带空顶点组**，让每个网格都带全部骨骼（作者说全骨骼有优化问题，但商家这么做就跟着做）；
2. **确实增减了骨骼 / 改了顶点组** ⇒ **必须全新 fbx 重新导入**，再用插件 **`Pumpkin's Avatar Tools`** 把旧模型的**组件 / 材质 / 动骨设置**复制到新模型（与 §4.3「复制组件 → 粘贴为新组件」同思路）。
   → 这类「换网格/换骨架」属于**结构性改动**，做完必须重新走验收（见 `07-01-bake-and-validation.md` §5、`07-02-evidence-and-ownership.md` §5 迁移职责清单）。

## §8 纪律

- **教程口径随版本漂移**：Blender 的 FBX 导出选项（实验性/叶骨）、PhysBone 1.0→1.1、MA/如梦 界面都会变。**照做前用工程实际版本核对**；对不上标 `STALE`、写清差异，不照旧视频硬找。
- **插件生成物（如梦衣柜、lilycalInventory、FaceEmo…）默认当输出**：改之前先确认能不能重新生成，能生成就别手改（`07-02-evidence-and-ownership.md` §6）。
- **Blender 侧改动不可逆性更高**（删顶点组、删骨骼、重建网格）：动手前先按 `06-02-backup-and-package.md` 备份，或至少把原 `.fbx` 留一份。
- **上传相关动作（登录、`Build & Test`、`Publish`、面板二次确认）是用户动作**；构建必须在 Unity GUI 模式下进行（`06-01-sdk-upload-and-versioning.md` §8）。
