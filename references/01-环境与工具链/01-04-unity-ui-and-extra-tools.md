# Unity 界面基础与周边工具

本册覆盖 Unity 基础操作之外的**界面细节**，以及三个**改模之外的配套工具**（Photon Studio / OVRAS / 一起看本地视频）。

## §0 与其它分册的分工

- `01-02 §6` = Unity 基础操作与工程组织的**知识点骨架**；本册 = **界面辨识细节 + 变量类型约束 + 周边工具**。
- 周边工具与改模无关（不影响模型质量），属「用得着再查」。

---

## §1 三个核心窗口与图标辨识

**Scene**（直观观察与编辑场景）

- 右键按住 + `WASD` 移动视角；
- 在 Hierarchy 里双击对象可直接把视角拉过去，**但模型中心点错误时视角会被拉得非常远，所以首选 WASD**；
- **Gizmos** 开关控制 Scene 中各种辅助图标、辅助线。

**Hierarchy**：管理 Scene 里的所有对象（与 Scene 本质关联）。

**Project**：类似文件管理器，左侧可快速选路径。

| 文件夹 | 用途 |
|---|---|
| `Assets` | 资源文件夹，可存放所有需要的资源（图片、音频、模型等） |
| `Packages` | 包/库文件夹，存官方与第三方的 Unity 工具和插件，由 **Unity 自动管理，一般不会用到** |

**图标辨识（易混！）**：文件夹 / **预制件（蓝色）** / **模型文件（左半全灰 + 一条黑线，最容易与预制件混淆）** / 材质球 / 场景。

## §2 Inspector 与 Avatar 的四个必备组件

选中角色顶层对象，会看到：

- `Transform`：位置（Position）、朝向（Rotation）、大小（Scale）；
- `Animator`：管理动画，决定何时播放哪个动画、如何在动画间切换；
- `VRC Avatar Descriptor`：**VRChat Avatar 必备组件**；
- `Pipeline Manager`：**VRChat Avatar 必备组件**。

展开子级（如 `Body`）会多出：

- `Skinned Mesh Renderer`：渲染皮肤，使皮肤**随骨骼移动**自然变形；
- `Material`：材质/贴图，决定表面颜色、纹理、光泽。

> 判据：**看不到 Descriptor 或 Pipeline Manager 的对象不是可上传的 Avatar**。

## §3 预制件编辑模式的三个特征

双击 Project 里的预制件即进入：

1. Hierarchy 窗口顶部**多出一个返回键**；
2. Scene 窗口标签下方**显示当前预制件名**；
3. **Scene 窗口背景变深蓝**。

- 在预制件模式里改动 → 退出后**所有场景中的该预制件同步更新**（这是预制件的意义：一次修改、多处更新）。
- 想断开联动：对象上右键 `Prefab → Unpack Completely`（官方术语「解压缩预制件实例」）。
- `Transform` 右侧三点菜单里有 **`Reset`**（归零）。
- 用 Unity Hub 新建项目时：选 **3D 核心模板**、**务必「创建在本地」**、**取消勾选「使用 Unity Version Control」**。

⚠️ **上传时不要在预制件编辑模式**（会直接失败，见 `01-03 §4.2`）。

## §4 窗口布局：作者的 2 by 3 方案

1. Unity 右上角**窗口预设** → `2 by 3`；
2. 把 `Hierarchy` 拖到 `Project` 的**上半部分**；
3. 在 `Project` 标签上右键 → `One Column Layout`；
4. 把 `Game` 标签拖到 `Scene` 标签**右侧**；
5. 顶部菜单 `Windows → General → Console` 打开控制台，放**左下角**。

（目的是最大化观察细节、方便调模型；熟手可自定义。）

## §5 Assets 与 Packages：导入判据（很实用）

**判断一个下载物该进 `Assets` 还是 `Packages`：**

| 下载物形态 | 去处 |
|---|---|
| `.unitypackage` | **直接用 Unity Editor 导入**（`Assets → Import Package → Custom Package`） |
| 压缩包，解压后文件夹里**含 `package.json`** | 进项目的 `Packages` 文件夹 |
| 其余压缩包 | 进 `Assets` |

- 手工装包时：下载**最新 `Latest` 版**；解压后逐个文件夹移进 `Packages`；回 Unity 等加载（**期间提示「无响应」属正常，不要强制关闭**）；顶部出现 `VRChat SDK` 菜单且能打开控制面板即成功。
- 为防误操作：点 Project 右上角**眼睛图标把 `Packages` 隐藏**。
- ⚠️ **不要轻易改 `Packages` 里的文件**，可能造成不可逆损坏。
- 手动装包需要下载的清单与镜像源替换见 `01-02 §2/§4`。

## §6 形态键（BlendShapes）基础用法

**概念**：模型像橡皮泥，形态键就是提前「捏好」的几种样子（笑、生气、鼓腮，以及缺胳膊少腿这类）。

**操作**：选中某部位网格 → 展开 `Skinned Mesh Renderer` → `BlendShapes` → 逐项调数值。衣物、道具上也可能带形态键。

**两条警告（重要）**：

1. **不是每个形态键都要改成 `0`**，要按模型实际情况微调，否则**可能出现穿模**。
2. 如果调整后进预览**不生效**，或出现**超出预期的模型扭曲**，说明该形态键**已被其它功能占用**（见动画控制器章节）→ **此时先不要调形态键**。

> 这两条正是 `../03-菜单与参数/03-03-case-study-and-sdk-panel.md` §7「部位消失 / 开关失效」排查的入口；也与基底 `../00-基底/00-05-mesh-blendshape.md` 的「形态键是共享资源，多消费者会互相打架」一致。

## §7 计算机变量基础（做菜单/开关前必读）

变量 = 贴了标签的杯子：**标签 = 名字**，**杯里的东西 = 值**，**容量 = 类型**。

| 类型 | 含义 | VRChat 同步范围 |
|---|---|---|
| `int` | 整数（0、1、-5、100、-1000） | **仅支持 0 – 255** |
| `float` | 浮点（3.14、-0.5、100.0、0.001） | **仅支持 -1.0 – 1.0** |
| `bool` | 只有 `true` / `false` | 二值 |

示例（只是示意，看懂类型含义即可）：

```csharp
int YinLiaoLiang = 0;      // 杯里有多少饮料，0 ~ 200ml
float TianDu = 0f;         // 甜度：0.0 不甜，1.0 最甜
bool GaiShang = false;     // 盖子盖上了吗

YinLiaoLiang = 200;        // 倒满牛奶
TianDu = 0.5f;             // 调到半糖
YinLiaoLiang = YinLiaoLiang / 2;  // 喝掉一半
GaiShang = true;           // 盖上盖子
```

⚠️ **同步范围是硬约束**：Int 超出 0–255、Float 超出 ±1.0 的部分**不会按预期同步**。参数成本与预算见 `../03-菜单与参数/03-01-parameter-and-menu-audit.md`，实际用法见 `03-02 §1`。

## §8 Photon Studio（Photoshop 平替）

- 由 **Tenzen.studio** 开发，**完全免费**、**自带中文界面**，功能与操作方式**与 Adobe Photoshop 完全一致**，有 PS 经验的无需重新学。
- 下载：官网；安装时建议选 **「为使用这台电脑的任何人安装」**，避免后续因权限问题导致文件无法写入。
- 切中文：点顶部菜单栏右侧的**地球图标**。
- 用途：`03-03 §8` 的**发色 / 挑染 / 眼睛贴图**绘制都可用它代替 Photoshop（很多人找不到 PS 安装包时尤其有用）。
- ⚠️ 素材版权：自己画的图 / 有授权的素材才用；不要分发他人付费素材。

## §9 OVR Advanced Settings（OVRAS，空间拖拽）

- 基于 SteamVR/OpenVR 的 VR 高级设置与悬浮工具，2016-09-11 上线；Steam 版已**转为付费**，另有 GitHub/网盘**免费版**。
- **用途**：让虚拟角色任意平移而本人不用走动，适合**小空间**使用。
- 快速配置流程（免费版）：
  1. 下载安装（涉及 VR 系统环境，**建议装到默认位置**）；
  2. 无需连 VR 设备，**在 Steam 库中直接启动 SteamVR**；
  3. SteamVR 菜单 → 设置 → **启动/关闭** → 「选择启动时的叠加界面应用」→ 开启 OVR Advanced Settings → **彻底退出 SteamVR**；
  4. 戴上 VR 设备从设备进入 SteamVR，听到提示音说明 OVRAS 已启动 → 从下方 Dock 栏选 OVRAS；
  5. 左侧 `Motion` → `Space Drag` 区域勾选 `Left Hand` / `Right Hand`（可都勾）；
  6. 返回 → 左下角 `Bindings` → **删掉所有现有按键配置**；
  7. 给要用的按键点 `+` → 选「按键」；再给重置键点 `+` → 选「按键」；
  8. 目标按键下「更多选项」→ 把「长按」右侧的「无」改成 `lefthandspacedrag`（拖拽）或 `resetoffsets`（重置）→ 左下角 `√` 保存；
  9. 同样处理另一个按键。
- **注意事项**：
  - 选的按键**不要与游戏内已有操作重复**（会按键冲突）；
  - 空间拖拽用于解决定位不准或狭小空间不便；**不建议长期用「按压摇杆」当拖拽键**——Quest 手柄是碳膜摇杆，长期按压会加快磨损；
  - 作者长期方案是**双击 Y 键拖拽、双击 A 键重置**（与 VRChat 菜单键/跳跃键冲突，但影响不大）。

## §10 和好友观看本地视频（组网 + HTTP 文件服务）

**原理**：用组网工具把主机与好友放进同一虚拟网络，再用支持 HTTP 的文件服务把本地视频通过**主机的虚拟 IP** 暴露出去，然后在 VRChat 播放器里播放该链接 → 只有同房间成员能看。

| 优势 | 劣势与警告 |
|---|---|
| 可以和指定好友一起看，其他人看不见 | 相当于直播，**消耗主机的上行速率** |
| 只要本地有视频就能立即播放，无需二次上传 | 只适合与**信赖**的好友**临时**观看；**有外链时优先用外链播放** |
| — | 每多一个好友多消耗一份「视频大小」的上行流量（n 个好友 = `视频大小 × n`）→ 视频**越小越好**，先自己压一遍，以免被运营商**限速或判为 PCDN**（商用专线除外） |
| — | 涉及 P2P，**国外网络、校园网或冷门运营商可能无法使用** |

**需要**：主机 = 组网工具（示例 Easytier 游戏版）+ 支持 HTTP 的文件传输工具（示例 CuteHttpFileServer）+ 视频文件；好友 = 同样的组网工具。

**步骤**：

1. （双方）打开组网工具，用公共服务器或自建节点；
2. （双方）输入**相同**的房间名与房间密码（公共服务器请尽量随机填），成员名各自填写 → 点「启动联机」→ 等上方显示绿色**联机成功**（一直灰色「联机中」= 服务器有问题）；
3. （双方）点「房间信息」看成员列表：双方应处于**直连（P2P）**而不是**转发（Relay）**；若某人显示 Relay，说明其网络不支持直连——**仍可播放但效果很差**；
4. （双方）记住**主机的虚拟网 IP**；
5. （仅主机）打开传输工具，通过自己的虚拟 IP 进网页 → 复制视频链接（链接里应是你的虚拟 IP）→ 粘到 VRChat 播放器播放。

⚠️ 原说明：**只提供思路，不提供任何下载，使用不当造成的一切后果自负**。本技能同样不提供任何下载链接或规避手段。
